# v0.2.2

Релиз `idle-shutdown-guard` с графическим управлением из трея и готовыми
пакетами для RPM/DEB систем.

## Что внутри

- Пользовательская systemd-служба для настольной Linux-сессии.
- Иконка в системном трее с меню статуса, настроек, ручной проверки и выхода.
- Форма настроек, которая сохраняет пользовательский конфиг в
  `~/.config/idle-shutdown-guard/config.ini`.
- Автоматическая сборка установочных `.rpm` и `.deb` пакетов для GitHub Release.
- XDG-autostart для массового распространения на рабочие станции через RedADM.
- Настройка часа, после которого можно начинать предупреждения.
- Проверка неактивности пользователя, по умолчанию 60 минут.
- Диалог предупреждения с возможностью отложить выключение на 60 минут.
- После отсрочки повторное предупреждение зависит от новой проверки
  неактивности: если пользователь работал, выключение не продолжается по
  старому таймеру.
- Автоматическое выключение, если предупреждение не отложили за 5 минут.
- Конфиг `/etc/idle-shutdown-guard/config.ini` и пользовательское переопределение через `~/.config/idle-shutdown-guard/config.ini`.
- RPM spec для сборки пакета на Fedora/RHEL-подобных системах.

## Проверка

- Основной Python-скрипт проходит синтаксическую проверку `py_compile`.
- Архив исходников `idle-shutdown-guard-0.1.0.tar.gz` собран с корневой папкой `idle-shutdown-guard-0.1.0`.

## Замечания

- Для X11 рекомендуется установить `xprintidle`.
- Для Wayland/современных desktop-сессий используется fallback через `systemd-logind`.
- Перед реальным тестом выключения лучше временно заменить `shutdown_command` на безопасную команду уведомления, как показано в README.
